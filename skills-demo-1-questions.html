Mock 1 — Coffee Shop Cash Till

  • Write a single-class Java cash-till program. Start at Customer 1 and ask how many coffees to order.
  • Use Scanner.nextLine() for the quantity and each menu choice, then Integer.parseInt() to convert them. Assume a positive whole-number quantity and whole-number choices.
  • Use a for loop for the requested quantity. Show Coffee 1 of 3, Coffee 2 of 3, and so on.
  • Use if / else if / else: option 1 is Small (€2.50); option 2 is Large (€4.00). Display the selection and price, add the charge and increase the sold count.
  • For another number display Invalid choice. It uses an entry but adds no coffee and no charge.
  • Print a receipt with customer number, coffees actually sold and total due. Use DecimalFormat for euros to two decimal places.
  • Use a do-while loop to ask Serve the next customer? (Y/N). Accept Y/y to continue, increment the customer number and reset the customer bill and count. Accept N/n to close.
  • At closing, display total coffees sold and total money taken across all customers. Treat each receipt total as paid.
  • Example: customer 1 choices 1,2,1 give 3 coffees and €9.00; customer 2 buys one large for €4.00. Till totals: 4 coffees and €13.00.

Mock 2 — GuessTheNumber

  • Write a single-class Java program called GuessTheNumber. Start at Game 1 with total wins and losses set to zero.
  • At the start of each game use Random to select a whole number from 1 to 10 inclusive. Reset the game state.
  • Use a for loop to allow up to five guesses. Display the attempt number, for example Guess 1 of 5.
  • Read each guess as a String using Scanner.nextLine(), then convert with Integer.parseInt(). Assume an entered whole number fits in an int.
  • Use if / else if / else: outside 1–10 displays Invalid guess and consumes an attempt; lower displays Too low!; higher displays Too high!; equal displays Correct! and attempts used, and ends the game early.
  • Use a boolean to track success. Record one win on success; after five unsuccessful attempts record one loss and reveal the secret number.
  • Use a do-while loop to ask Play a new game? (Y/N). Accept Y/y to increment the game number and start again; N/n finishes. Assume one of these replies.
  • At the end, display total games won and total games lost for the session.
  • Example with secret 7: guesses 4,9,7 win on attempt 3. Ending then gives total wins 1 and losses 0.

What to submit

  • Expected and actual results, screenshots, and corrections with retest results.
  • OneDrive recording link and the brief as directed by your teacher.
